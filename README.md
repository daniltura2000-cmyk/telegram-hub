# TelegramHub 🤖

Самохостинговий Telegram-бот, який підключає **ваш власний акаунт** (MTProto через Telethon) і відповідає на вхідні повідомлення **від вашого імені** штучним інтелектом — у вашому стилі письма. Уся конфігурація — через зручне меню контрольного бота (Bot API), українською.

> ⚠️ **ПОПЕРЕДЖЕННЯ ЩОДО БЕЗПЕКИ ТА ВІДПОВІДАЛЬНОГО ВИКОРИСТАННЯ**
> Автоматизація особистого акаунта Telegram (userbot) **може порушувати Умови користування Telegram** і призвести до обмеження або видалення акаунта. Ви використовуєте TelegramHub на власний ризик і несете повну відповідальність за те, як і для чого він відповідає від вашого імені. Не використовуйте його для спаму, масових розсилок чи обману людей. Завжди попереджайте співрозмовників, якщо авто-відповіді можуть вводити їх в оману.

## Можливості

- 🔑 **API ключі ШІ** — OpenAI-сумісні (base_url + ключ + модель), Anthropic, Google Gemini. Кілька ключів, один активний, перемикання в меню. Ключі зберігаються локально в SQLite і ніколи не показуються повністю (лише останні 4 символи).
- 👤 **Підключення акаунта** — покроковий діалог: api_id → api_hash → телефон → код → пароль 2FA (за потреби). Сесія Telethon зберігається в `sessions/<user_id>.session`.
- 📝 **Промпт** — базовий системний промпт: перегляд, редагування, скидання до стандартного.
- 🧠 **Аналіз стилю** — бот збирає **ваші власні** вихідні повідомлення (один чат, кілька обраних чатів або вся переписка, до 500 повідомлень на чат) і через LLM створює стислий профіль вашого стилю українською (тон, словник, довжина речень, емодзі, вітання/прощання, звички). Профіль можна переглянути та перегенерувати.
- ⚙️ **Налаштування авто-відповідей** — увімк/вимк; режим «лише обрані чати» або «всі, крім ігнорованих»; ігнор-лист (ID/username); випадкова затримка відповіді (мін/макс); максимальна кількість частин відповіді; ліміт контексту; кулдаун на чат; режим «лише згадки/приватні».
- 📊 **Статус** — стан акаунта, ключів, авто-відповідей та останніх помилок.
- 🧍 **«Людське» надсилання** — випадкова затримка перед відповіддю, індикатор «друкує» пропорційно довжині тексту, довгі відповіді розбиваються на 2–3 частини з паузами, markdown-артефакти та дислеймери про ШІ прибираються.

## Швидкий старт

```bash
git clone <repo> && cd TelegramHub
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env   # і заповніть TELEGRAM_BOT_TOKEN та ADMIN_IDS

python -m tg_hub.main
```

1. Створіть бота в [@BotFather](https://t.me/BotFather) → скопіюйте токен у `TELEGRAM_BOT_TOKEN`.
2. Дізнайтеся свій Telegram ID (наприклад через [@userinfobot](https://t.me/userinfobot)) → внесіть у `ADMIN_IDS`.
3. Запустіть застосунок і надішліть боту `/start` — з'явиться головне меню.

## Як отримати api_id / api_hash

1. Відкрийте [my.telegram.org](https://my.telegram.org) і увійдіть за номером вашого акаунта.
2. Оберіть **API development tools**.
3. Створіть застосунок (назва/опис — довільні), після чого ви побачите **api_id** (число) та **api_hash** (рядок із 32 символів).
4. Внесіть їх у меню «Підключити акаунт» у контрольному боті (або в `.env` як `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` — тоді вони підставлятимуться за замовчуванням).

## Структура проєкту

```
tg_hub/
├── main.py            # точка входу: Telethon + aiogram в одному asyncio-циклі
├── config.py          # змінні оточення та .env
├── db.py              # SQLite (stdlib sqlite3 через asyncio.to_thread)
├── control_bot.py     # контрольний бот: меню, FSM, налаштування
├── userbot.py         # Telethon-клієнт + движок авто-відповідей
├── keyboards.py       # клавіатури
├── texts.py           # українські тексти інтерфейсу
├── logging_setup.py   # логи: консоль + logs/hub.log (ротація)
├── llm/               # провайдери LLM (тільки httpx): openai_compat, anthropic, google
└── persona/           # аналіз стилю та константи промптів
tests/                 # юніт-тести (pytest, без мережі)
```

Дані зберігаються у `data/hub.db` (SQLite), сесії — у `sessions/`, логи — у `logs/hub.log`. Усі ці каталоги та `.env` у `.gitignore`.

## Етичне використання

- Автовідповідь не приховує того, що це автоматизація, якщо ви самі не розкрили це співрозмовникам — будьте чесні.
- Не налаштовуйте бота відправляти повідомлення людям, які не очікують відповіді.
- Регулярно перевіряйте «Статус» — у разі помилок бот повідомить адмін-чат.
